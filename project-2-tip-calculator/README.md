# 💸 Tip Calculator

A simple Python program that calculates how much each person should pay when splitting a bill, including a chosen tip percentage.

## How It Works

1. Enter the total bill amount.
2. Choose the tip percentage.
3. Enter the number of people splitting the bill.
4. Get the amount each person should pay.

## Concepts Practised

- Getting user input with `input()`
- Converting input using `float()` and `int()`
- Variables and arithmetic operations
- Calculating percentages
- Using `round()` and f-strings
- Formatting monetary values

## Example Output

```text
Welcome to the tip calculator!
What was the total bill? $150
What percentage tip would you like to give? 10 12 15
How many people to split the bill? 3
Each person should pay: $55.00
```

## How to Run

Make sure Python is installed, then run:

```bash
python main.py
```
