# 🎸 Band Name Generator

My first Python project! This simple program generates a potential band name using the city you grew up in and your pet's name.

## How It Works

1. Enter the city you grew up in.
2. Enter your pet's name.
3. Get a suggested band name combining both answers.

## Concepts Practised

- User input with `input()`
- Displaying output with `print()`
- Variables and strings
- String concatenation

## Example Output

```text
Welcome to the Band Name Generator.
Which city did you grow up in?
Mumbai
What is the name of a pet?
Bruno
Your band name could be Mumbai Bruno
```

## How to Run

Make sure Python is installed, then run:

```bash
python main.py
```

## What I Learned

This project helped me practise collecting user input, storing information in variables and combining strings to generate an output.
