# 🏝️ Treasure Island Game

A text-based adventure game built with Python where the player's mission is to find the hidden treasure. Every decision matters, and one wrong turn can lead to Game Over!

## 🎮 How It Works

1. Start your adventure at a crossroad.
2. Choose to go left or right.
3. If you go left, decide whether to wait for a boat or swim across the lake.
4. If you wait for the boat, you'll reach an island with three doors: red, yellow, and blue.
5. Choose a door and discover your fate!

Find the treasure to win the game. Choose incorrectly, and your adventure ends.

## 🛠️ Concepts Practised

- Taking user input with `input()`
- Converting input to lowercase with `.lower()`
- Conditional statements (`if`, `elif`, `else`)
- Nested conditional statements
- String handling and formatted prompts
- Using ASCII art to create a visual introduction
- Building a simple interactive game with branching choices

## 🏆 Possible Outcomes

- **Go right:** Fall into a hole — Game Over.
- **Swim across the lake:** Get attacked by an angry trout — Game Over.
- **Choose the red door:** Enter a room full of fire — Game Over.
- **Choose the blue door:** Enter a room of beasts — Game Over.
- **Choose the yellow door:** Find the treasure and win!

## ▶️ How to Run

Make sure Python is installed on your computer, then run:

```bash
python main.py
```
