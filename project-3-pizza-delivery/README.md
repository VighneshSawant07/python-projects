# 🍕 Pizza Delivery Program

A simple Python program that calculates the total cost of a pizza based on its size, pepperoni preference, and whether extra cheese is requested.

## 📌 How It Works

1. Choose a pizza size: Small (`S`), Medium (`M`), or Large (`L`).
2. Choose whether you want pepperoni.
3. Choose whether you want extra cheese.
4. The program calculates and displays the final bill.

## 💰 Pricing

| Item | Price |
|---|---:|
| Small pizza | $15 |
| Medium pizza | $20 |
| Large pizza | $25 |
| Pepperoni on a small pizza | $2 |
| Pepperoni on a medium or large pizza | $3 |
| Extra cheese | $1 |

## 🛠️ Concepts Practised

- Getting user input with `input()`
- Using variables to store choices and calculate prices
- Conditional statements (`if`, `elif`, `else`)
- Comparison operators
- Arithmetic operators (`+=`)
- Nested conditional statements
- F-strings for displaying the final bill

## 💻 Example Output

```text
Welcome to Python Pizza Deliveries!
What size pizza do you want? S, M or L: M
Do you want pepperoni on your pizza? Y or N: Y
Do you want extra cheese? Y or N: Y
Your final bill is: $24.
```

## ▶️ How to Run

Make sure Python is installed on your computer, then run:

```bash
python main.py
```
