# 🪨 Rock Paper Scissors

A simple command-line Rock Paper Scissors game built with Python. Play against the computer, which randomly chooses rock, paper, or scissors, and see who wins!

## 🎮 How to Play

1. Run the program.
2. Enter `0` for Rock, `1` for Paper, or `2` for Scissors.
3. The computer randomly selects its move.
4. The program displays both choices and announces the result.

## 🏆 Game Rules

- **Rock beats Scissors**
- **Scissors beats Paper**
- **Paper beats Rock**
- If both players choose the same option, it's a draw.

## 🛠️ Concepts Practised

- Importing and using Python's `random` module
- Variables and lists
- Taking user input with `input()`
- Converting input to an integer with `int()`
- Generating random numbers with `random.randint()`
- List indexing
- Conditional statements (`if`, `elif`, `else`)
- Comparison and logical operators
- Displaying ASCII art in the terminal

## ▶️ How to Run

Make sure Python is installed on your computer, then run:

```bash
python main.py
```

No external libraries are required because the program uses Python's built-in `random` module.
